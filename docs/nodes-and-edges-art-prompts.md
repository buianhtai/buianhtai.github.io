# Nodes & Edges — ChatGPT Cover Art Prompts

Consistent series art for the Substack publication. Paste the STYLE BLOCK, then one SUBJECT line per post into ChatGPT (GPT-4o image generation).

## Rules

- Never ask for labeled technical diagrams — AI garbles text. Covers are conceptual/mood only.
- Engineering diagrams stay SVG→PNG from the existing pipeline.
- Download at highest resolution offered; crop to 1456×816 (Substack hero ratio) if needed.

## Style Block (prepend to every prompt)

```text
Flat vector editorial illustration, generous negative space, muted palette of deep navy (#1e3a5f), warm cream (#faf7f5), gold (#d4a73a) and terracotta (#c2410c) accents on a paper-textured background. Minimal geometric shapes suggesting connected nodes and edges. No text, no letters, no words anywhere in the image. Wide 16:9 composition with the focal subject slightly right of center, leaving calm space on the left.
```

## New-post workflow

1. Copy Style Block
2. Write one subject sentence describing the post's core metaphor
3. Generate 2–3 variants, pick one, download
4. In Substack editor: upload as cover, set alt text
