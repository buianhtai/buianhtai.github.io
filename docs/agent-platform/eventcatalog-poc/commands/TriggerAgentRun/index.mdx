# Trigger Agent Run

**Status: proposed versioned interface, not evidence of a deployed implementation.**

Normalize a verified external event into idempotent run admission.

<NodeGraph />

## Contract semantics

The incoming payload cannot choose the target agent or grant a new principal. The trigger binding specifies both; the sourceEventId is deduplicated before admission.

## Field reference

| Field | Type | Meaning |
| --- | --- | --- |
| bindingId | string | Required; validated against authority-owned data |
| sourceEventId | string | Required; validated against authority-owned data |
| sourceType | string | Optional contextual reference |
| principalRef | string | Least-privileged service identity |
| payloadRef | string | Optional contextual reference |
