# Delegate Agent Run

**Status: proposed versioned interface, not evidence of a deployed implementation.**

Create a bounded child run against a previously approved subagent alias.

<NodeGraph />

## Contract semantics

The target is resolved from a pinned parent-agent binding, not a global lookup. Deduplication keeps one child per delegation identity, with limited context and permissions.

| Field | Type | Meaning |
| --- | --- | --- |

| delegationId | string | Required; validated against authority-owned data |
| subagentAlias | string | Required; validated against authority-owned data |
