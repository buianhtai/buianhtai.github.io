# Agent Version Published

**Status: proposed versioned interface, not evidence of a deployed implementation.**

Indicates that a validated immutable agent version is available for deployment alias resolution.

<NodeGraph />

## Contract semantics

Publishing is not starting a run. Existing runs remain on their previously pinned versions; deploying the new alias is a separate authorized step.

## Field reference

| Field | Type | Meaning |
| --- | --- | --- |
| agentId | string | Required; validated against authority-owned data |
| version | string | Required; validated against authority-owned data |
| manifestDigest | string | Pinned executable configuration fingerprint |
| publishedAt | string | Optional contextual reference |
| traceId | string | Trace correlation |
