# Tool Invocation Completed

**Status: proposed versioned interface, not evidence of a deployed implementation.**

Records the normalized outcome of one reviewed tool invocation.

<NodeGraph />

## Contract semantics

OUTCOME_UNKNOWN is distinct from FAILED: a remote write may have been accepted before its acknowledgment was lost, so retry requires reconciliation.

## Field reference

| Field | Type | Meaning |
| --- | --- | --- |
| runId | string | Tenant-scoped logical run reference |
| invocationId | string | Required; validated against authority-owned data |
| toolVersionRef | string | Optional contextual reference |
| outcome | string | Required; validated against authority-owned data |
| resultRef | string | Optional contextual reference |
| completedAt | string | Optional contextual reference |
