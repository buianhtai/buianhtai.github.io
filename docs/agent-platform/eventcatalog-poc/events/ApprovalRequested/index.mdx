# Approval Requested

**Status: proposed versioned interface, not evidence of a deployed implementation.**

Signals that a run is paused awaiting human approval of exact side-effect intent.

## Contract semantics

A user-facing notification references a safe preview; it does not carry private connector credentials, unrestricted raw payloads or approval powers.

## Field reference

| Field | Type | Meaning |
| --- | --- | --- |
| approvalId | string | Required; validated against authority-owned data |
| runId | string | Tenant-scoped logical run reference |
| intentHash | string | Canonical operation and arguments hash |
| expiresAt | string | Optional contextual reference |
| reviewerPolicyRef | string | Optional contextual reference |
