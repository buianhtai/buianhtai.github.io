# RunCompleted

**Proposed event/notification contract, not implemented.** Indicates that the platform has committed a successful terminal run result. Failure/cancellation events would be separate future resources.

Suggested safe fields: `runId`, `resultRef`, `completedAt`, `usageSummary`, `traceId`. This does not imply any external write executed exactly once.
