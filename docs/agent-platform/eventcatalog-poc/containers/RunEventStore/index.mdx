# Run and Event Store

**Proposed logical data store, not an installed database or cloud resource.**

Durability and per-run ordering are requirements; a single physical database is not prescribed.

## Native data dependencies

<NodeGraph mode="full" />

Data residency, retention policy, RPO/RTO and encryption-key ownership require separate architecture and compliance decisions. Linked services declare `readsFrom` and `writesTo` relationships so EventCatalog can derive dependency graphs automatically.
