## Lifecycle and invariants

A logical run is created atomically with an outbox dispatch intent before HTTP 202. At-least-once queue delivery may create multiple attempts but not multiple logical run records. Workflow engines own internal steps; the Run Service owns the public projection, audit, terminal result and policy envelope.

## Fictional example

A worker crashes after a read-only search. The resumed attempt reuses the runId and pinned configuration, and a fencing token prevents the stale worker from committing.
