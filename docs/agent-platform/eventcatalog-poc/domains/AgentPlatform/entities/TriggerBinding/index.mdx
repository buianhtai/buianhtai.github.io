## Lifecycle and invariants

Trigger adapters verify source authenticity and deduplicate deliveries before run admission. Payloads must not override the target deployment, model privileges, credentials or tenant. A scheduled source and a direct chat message can both initiate a run, but the admission protocol remains the same.

## Fictional example

A support mailbox trigger binds verified message events to a low-cost triage workflow with a scoped support service principal.
