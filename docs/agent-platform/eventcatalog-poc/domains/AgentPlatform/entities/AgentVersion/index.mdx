## Lifecycle and invariants

Publishing validates tools, skills, subagent bindings, model compatibility and policy before producing a digest. A run pins this digest; changing the draft or active alias must not mutate an admitted run. A rollback switches an alias to an earlier published revision rather than rewriting history.

## Fictional example

A documentation assistant is published as version 2. An existing session continues version 1 under its pinned policy; new sessions can resolve version 2 after publication.
