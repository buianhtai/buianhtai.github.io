## Lifecycle and invariants

An approval is not a blank permission token. It authorizes only the exact tool version, target, arguments and risk classification bound by intentHash. Before executing, policy and ACLs must be re-evaluated. Rejection or expiration must never trigger an external write.

## Fictional example

A generated customer-email draft waits for an authorized reviewer. Editing its recipients or body invalidates the prior approval hash.
