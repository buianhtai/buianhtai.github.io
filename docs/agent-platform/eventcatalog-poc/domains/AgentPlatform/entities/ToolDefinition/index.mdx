## Lifecycle and invariants

A tool is not an unrestricted URL or shell command. Tool versions define input/output schemas, execution semantics, risk class, and reviewed provider operation. Connector instances carry per-tenant endpoint and credential references separately. Any model-generated arguments must be schema-validated and checked again at invocation.
