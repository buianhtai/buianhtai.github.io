## Lifecycle and invariants

A binding may reduce but never expand the capability granted by a ToolDefinition. The Tool Gateway intersects bound restrictions with the caller/service principal, tenant and resource ACLs on each invocation. Binding publication and runtime authorization are separate checks.

## Fictional example

The support agent may search only approved documentation collections, up to five calls per run, without write access.
