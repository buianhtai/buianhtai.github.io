## Interpretation

**The model cannot authorize external calls or supply arbitrary shell commands/URLs.** The tool boundary owns version resolution, schema validation, ACL, budget, immutable approval, allowed adapter execution and reconciliation. Connector installation identity is distinct from a ToolDefinition and per-agent ToolBinding. External A2A delegation follows its own gateway rather than pretending to be an unrestricted MCP tool.

## Adapter extension points

| Adapter | Reviewed configuration | Security gate | Failure / replay |
| --- | --- | --- | --- |
| MCP | Allowed server instance, exposed tool version | Per-tool/argument/tenant scopes | Safe read retries; bounded result sizes |
| Typed REST | Allowlisted host+operationRef, schema, credentialRef | Egress, ACL, quota, explicit write privilege | Stable invocationId, remote status |
| External job | Pinned template/image, approved runner, callback auth | Often human approval of exact intent | UNKNOWN effect -> reconcile, never blind retry |
| Model gateway | Model profile and approved deployment | Tenant data policy, token and spend budget | Approved fallback only |
| Delegation | Pinned subagent alias, parent budget and rights intersection | Scoped child run with max depth | Child terminal event or bounded timeout |

## Key distinctions

**Approval requested** does not mean approval granted. **Approval granted** does not mean the external effect succeeded. **Remote timeout** does not prove the effect failed. These distinctions must appear in logs, status, result contracts and recovery tests.
