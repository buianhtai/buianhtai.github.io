**Status: proposed design.** Fictional, domain-neutral, and implementation-neutral; not evidence of deployed cloud infrastructure or an approved technology stack.

## How to read it

Trust changes at four points: inbound source verification, tenant/principal authorization, untrusted model-to-tool crossing, and human-approved side effects. Prompt text is not an ACL. Never allow arbitrary shell scripts, arbitrary URLs or secret expansion from model output; risky effects must be reviewed as a fixed operation and audited.
