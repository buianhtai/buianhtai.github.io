# C4 Level 2 — Containers

**Status: proposed design.** Fictional, domain-neutral, and technology-agnostic. This is an architectural view, not a live infrastructure map.

## How to read it

**C4 container is not a microservices prescription.** Multiple logical control-plane services may share a deployment in an MVP. The durable queue/outbox and operational stores remain explicit because they are part of the reliability contract. Workers are separate from public HTTP/SSE processing.
