## How to read it

Conceptual **logical data** rather than an endorsed physical SQL schema. AgentVersion is immutable; AgentRun is the user-facing durable identity; RunAttempt may repeat; ToolInvocation and ApprovalRequest retain effect provenance; RunEvent provides ordered replay. Physical implementations may divide these across transactional, event and object stores.
