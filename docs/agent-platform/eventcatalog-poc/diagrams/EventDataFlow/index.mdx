# Durable Data and Event Flow

**Status: proposed design.** Fictional, domain-neutral, and implementation-neutral; not evidence of deployed cloud infrastructure or an approved technology stack.

## How to read it

An outbox transaction prevents accepted requests from disappearing between database commit and dispatch. At-least-once delivery means checkpoint and tool invocation ledgers must be idempotent. Store sensitive result payloads behind scoped artifacts; stream normalized events and references only. The Run Service owns public state even if an engine owns its internal checkpoint format.
