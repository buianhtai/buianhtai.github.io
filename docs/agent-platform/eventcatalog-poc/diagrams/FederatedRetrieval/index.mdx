## Retrieval policy and failure behavior

A selected or routed agent has a **published version binding** to a set of **approved source capabilities**, not unrestricted access to every catalog connector. The coordinator plans a **subset** of eligible sources; each connector and individual result still respects tenant/workspace permissions. Indexed results must carry ACL, source revision and ingest watermark.

Use live API reads for fresh authoritative records, indexed retrieval for stable knowledge, and hybrid keyword/vector search where both exact identifiers and semantic meaning matter. Merge rankings carefully (e.g. reciprocal rank fusion) rather than average heterogeneous search scores. Evidence must fit a bounded context with timestamps and source citations.

Independent sources can run concurrently behind a fan-out limit, global deadline, per-provider rate limits and circuit breakers. A source timeout becomes an explicit partial-source status where policy permits—not an invented or silently complete answer.
