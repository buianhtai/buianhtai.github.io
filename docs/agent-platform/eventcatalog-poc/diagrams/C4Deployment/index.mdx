**Status: proposed design.** Fictional, domain-neutral, and implementation-neutral; not evidence of deployed cloud infrastructure or an approved technology stack.

## How to read it

**Deployment hypothesis, not a cloud architecture decision.** Regional placement, provider choice, HA/RPO/RTO, managed vs self-hosted stores and workflow engine are open. The immutable requirements are separate API and worker scaling, durable run admission, controlled egress, confidential connector secrets, and survivable worker restarts.
