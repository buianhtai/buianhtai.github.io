## How to read it

A connector installation and a ToolDefinition are **not** the same thing: the former holds reviewed destination/credential refs; the latter defines a stable capability. ToolBinding narrows an agent's access. Triggers initiate runs, models propose actions, and delegation starts child runs; none bypass gateway checks.
