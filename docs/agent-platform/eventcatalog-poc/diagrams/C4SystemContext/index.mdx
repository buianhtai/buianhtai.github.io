# C4 Level 1 — System Context

**Status: proposed design.** Fictional, domain-neutral, and technology-agnostic. This is an architectural view, not a live infrastructure map.

## How to read it

The platform boundary includes its API, run state, policy, worker coordination and gateways. Models and remote job runners are **external systems**, not trusted extensions of the model. The human reviewer acts independently of the agent. This C4 context view intentionally excludes internal services and database technology.
