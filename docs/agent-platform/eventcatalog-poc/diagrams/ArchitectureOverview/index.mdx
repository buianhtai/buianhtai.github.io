## How to read it

**Read left to right.** Only Platform API or a verified trigger adapter admits work; the Run Service creates a durable run before dispatch; the worker executes a pinned runtime; model, tool and delegation calls cross independent policy boundaries. Event streaming reads durable events, not worker sockets.
