# Run Dispatcher

**Proposed logical component.** Consumes durably accepted work, schedules execution, manages worker leases and retries. Direct queue and durable-workflow implementations are alternatives, not simultaneously required. Delivery can be at least once; execution is protected by idempotency and fencing.
