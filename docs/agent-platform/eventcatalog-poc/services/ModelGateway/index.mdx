# Model Gateway

**Status: proposed logical component; not evidence of a deployed service.**

<NodeGraph />

## Model selection

A model profile points to an approved endpoint/deployment, token and context limits, runtime settings, data-handling rules and optional fallback chain. Authorization of tools remains external to the model.

| Task | Default | Escalation |
| --- | --- | --- |
| Spam and known FAQ | Deterministic rules | None |
| Intent classification | Economical small model | Low confidence to human or approved larger model |
| Grounded answer | Cost-effective model + retrieval | Missing evidence / output validation failure |
| Complex reasoning | Reasoning-capable model, limited depth | Only when preauthorized by budget |

~~~yaml
modelProfileRef: support-economical@1
maxInputTokens: 4000
maxOutputTokens: 800
timeoutSeconds: 25
fallbackProfileRefs: []
~~~

## Reliability and cost

Enforce provider RPM/TPM, per-tenant concurrency, request deadline, token budget and hard total spend. Fallback never silently sends sensitive data to a provider outside the approved policy. Record cost, latency, quality evaluation and escalation reason per agent revision. Model retries do not imply tool retries.
