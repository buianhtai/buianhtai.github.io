# Agent Worker

Loads an immutable agent manifest and executes it through an approved `RuntimeAdapter`. It emits progress and result events to the Run Service/Event Store, and it cannot bypass tool authorization.

Worker-to-worker delegation uses a scoped child run, not unrestricted sharing of execution credentials.
