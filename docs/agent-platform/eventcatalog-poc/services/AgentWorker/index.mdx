# Agent Worker

**Status: proposed logical component; not evidence of a deployed service.**

<NodeGraph />

<CustomProperties title="Architecture governance" />

## Attempt lifecycle

1. Claim a run using an atomic fenced lease; load the immutable manifest digest, limits, tenant and effective principal.
2. Resume from a safe checkpoint and invoke the appropriate RuntimeAdapter.
3. Pass every requested external operation through Tool Gateway, preserving the invocationId for retries and audit.
4. Persist checkpoints, normalized progress and usage; commit terminal status only while holding the latest fencing token.
5. Release reservations and acknowledge dispatch after persistence succeeds.

## Recovery matrix

| Incident | Worker behavior |
| --- | --- |
| Model timeout | Bounded retry or typed failure |
| Tool denied | Audit denial; answer safely or fail |
| Worker crash | Lease expiry, safe checkpoint resume |
| Unknown external write | Reconciliation, not blind retry |
| Agent revised mid-run | Continue pinned revision |
| Parent run cancelled | Best-effort child/job cancellation |

Workers are not browser servers. SSE comes from the EventStreamAPI and committed event store. Separate simple, deep and external-job pools only when load demands it. Track per-run tokens, cost, tool latency, retry count and trace correlation.
