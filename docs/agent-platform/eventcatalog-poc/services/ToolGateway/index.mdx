# Tool Gateway

Checks effective principal, agent/tool binding, argument schema, tenant/resource access, budgets, and approval policy. It invokes only registered and reviewed operations.

Shell execution is restricted to approved job templates on isolated external runners; no general free-form shell command capability is implied.
