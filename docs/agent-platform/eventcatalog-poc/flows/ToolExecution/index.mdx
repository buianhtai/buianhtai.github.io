# Authorized Tool Execution

**Status: proposed.** The model cannot self-authorize a tool call. The gateway enforces tool bindings and caller/resource permissions before any adapter call.

<NodeGraph />

Only read-only tool execution is illustrated here. External scripts, writes and approval-gated jobs require stronger isolated runner and reconciliation contracts; see the [tool registry architecture](https://github.com/buianhtai/buianhtai.github.io/blob/docs/agent-platform-invocation-architecture/docs/agent-platform/04-tool-registry-and-external-execution.md).
