# Approval-Gated External Job

**Status: proposed design, not deployed workflow code.** Native EventCatalog Flow nodes below link directly to referenced services, commands and events.

<NodeGraph />

## The scenario

A report assistant proposes the named capability "reports.run_preview@2". Unlike an unrestricted shell command, this maps to a **reviewed operation**, fixed runtime image/workflow and allowlisted endpoint. The request carries a validated period and an immutable invocationId.

## Control plane versus effect

~~~mermaid
sequenceDiagram
    participant W as Worker
    participant G as Tool Gateway
    participant A as Approval Service
    actor H as Reviewer
    participant E as External Runner
    W->>G: reports.run_preview(period=week)
    G->>G: Validate tool version, grants, budget
    G->>A: RequestApproval(intentHash)
    A-->>H: Exact operation preview
    H->>A: Approve intentHash
    A-->>G: ApprovalResolved
    G->>G: Recheck policy and exact hash
    G->>E: Invoke reviewed operation with invocationId
    alt Confirmed result
      E-->>G: remoteId and terminal status
      G-->>W: Typed ToolInvocationCompleted
    else Unknown remote effect
      E--xG: Timeout after possible acceptance
      G-->>W: OUTCOME_UNKNOWN; reconciliation needed
    end
~~~

## Reliability rules

The user cannot configure an arbitrary shell, network URL or script body through a prompt. External effects require approved adapter installations, immutable operation references and narrow credentials. A worker may release its lease while awaiting a human or remote callback; the durable Run Service continues to track WAITING_APPROVAL or external-job wait reason. An **OUTCOME_UNKNOWN** result may represent a successful remote write: reconcile using remoteId/idempotency keys, never blindly repeat.

## Acceptance checks

A rejected, changed or expired approval leads to zero side effects. Replaying a gateway invocation uses the same invocationId. A malformed argument fails schema validation before contacting an external endpoint. Human reviewer and service principals are independently authorized. The worker never owns a direct browser connection.
