# Architecture Stewards

**Proposed role, not an assertion that a team with this name currently exists.**

This logical ownership group reviews architecture decision proposals, coherence of flows, schema compatibility, threat boundaries and catalog changes. A platform owner should replace this placeholder with the organization's real team identity and contact route.

## Responsibilities

- Review proposed ADRs before changing status to accepted
- Verify source code, ownership, tickets and implementation status when services are actually built
- Approve breaking contract changes, migration paths and event-version transitions
- Keep the catalog generic and free of customer/internal project secrets

**Escalation:** use repository pull-request review until a real maintainer or contact is assigned.
